# Флорика

Приложение для цветочных салонов: чек-лист смены с КПД, график по точкам, зарплата флористов с процентом и премиями,
итоги по накладным, чаты и пульт руководителя.

Сайт: https://egorr24.github.io/florist-checklist/ · связь: [@helperdev42](https://t.me/helperdev42)

Сотрудникам: [скачать приложение](https://egorr24.github.io/florist-checklist/download.html) · APK — во вкладке
[Releases](https://github.com/egorr24/florist-checklist/releases/latest). Приложение само проверяет новые релизы и предлагает обновиться.
